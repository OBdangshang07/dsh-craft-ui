# Asset policy

## Distributed by this repository

- Original pixel textures generated by `scripts/generate-assets.mjs`.
- Original sprite icons and nine-slice frames.
- Fusion Pixel 10px Monospaced zh-Hans WOFF2 under SIL Open Font License 1.1, with its license and bundled-component notices retained in `assets/fonts/`.
- Original synthesized Web Audio cues implemented as oscillator envelopes.
- Source code, documentation, and tests under the repository license.

## Never distributed by this repository

- Minecraft or Mojang logos.
- Official Minecraft textures, sounds, fonts, screenshots, or JAR contents.
- User-selected resource packs or their extracted cache.

## Bundled runtime assets

The build replaces every `__ASSET_*__` stylesheet placeholder with a data URL. Default textures and the UI font therefore travel inside `lib/client.js` and require no network or system-font lookup at runtime. Their source files remain in `assets/generated/` and `assets/fonts/` for package inspection. The package verifier checks the font against the reviewed SHA-256 digest, while the tarball audit accepts only the named WOFF2 and its license.

## Local import boundary

Official or third-party item assets may be used only when the user explicitly selects a locally owned textures directory. The Host reads a fixed item-name whitelist into a private cache and exposes only selected runtime item sprites to the loopback Client. UI frames, buttons, bars, slots, and backgrounds remain original. Imported files are excluded from package contents and source control.

The selected directory must be an absolute path. Each candidate item file is resolved to its canonical `realpath` and must remain inside that directory, so a symbolic link cannot make the importer read an outside file. Accepted images must have a valid PNG/IHDR header, be square power-of-two images between 16 and 256 pixels, and remain at or below 64 KB each.

Cache manifests describe imported capabilities and content hashes but do not retain the source directory. Imported bytes stay in the user's private `$DSH_HOME/craft-ui/resource-packs` cache and are never part of the repository or release tarball. The release audit enforces that boundary independently of source-control ignore rules.

Open-source or non-commercial distribution does not by itself grant permission to redistribute copyrighted game assets. Contributors must keep all default and test fixtures original or synthetic.
